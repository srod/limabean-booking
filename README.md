# limabean-booking

> **This is a fork**, published on crates.io as `ledgermill-beancount-booking` for
> [ledgermill](https://github.com/srod/ledgermill). It is upstream
> [limabean-booking](https://github.com/tesujimath/limabean-booking) depending on
> `ledgermill-beancount-parser` (beancount-parser-lima without its GPL files) instead of
> `beancount-parser-lima`; the code is otherwise unchanged. Use upstream unless you need that.

This is a generic implementation of the Beancount booking algorithm, with no dependencies on either the [Lima parser](https://github.com/tesujimath/beancount-parser-lima) nor [limabean](https://github.com/tesujimath/limabean) itself.

For further information see the [API documentation](https://docs.rs/limabean-booking/latest/limabean_booking/).
